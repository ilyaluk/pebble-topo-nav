# Coding Guidelines Compliance

Agents must strictly adhere to the following rules during development in this project:
- **Read Guidelines:** You MUST read the `coding_guidelines.md` before starting any feature development.
- **English User Stories:** Assume that User Stories and Acceptance Criteria are written in English (typically as GitHub Issues).
- **Branch Naming & Commits:** Adhere to the branch naming convention (`feature/US-[ID]-...`) and use Conventional Commits for commit messages.
- **Definition of Done:** You MUST maintain and update both `README.md` and `CHANGELOG.md` as required by the Definition of Done.
